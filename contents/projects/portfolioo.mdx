## 🚀 Cara Pemasangan & Persiapan

Ikuti langkah-langkah di bawah ini secara berurutan untuk menjalankan proyek `portfolioo` di lingkungan lokal Anda.

### Prasyarat
Pastikan komputer Anda telah menginstal perangkat lunak berikut:
- [Node.js](https://nodejs.org/) (Versi 18.x atau terbaru)
- [Git](https://git-scm.com/)
- [Bun](https://bun.sh/) (Disarankan) atau npm/yarn sebagai package manager.

### Langkah Instalasi

1. **Clone Repository**
   Buka terminal Anda dan jalankan perintah berikut untuk mengunduh kode sumber:
   ```bash
   git clone https://github.com/saecar/portfolioo.git
   cd portfolioo
   ```

2. **Instalasi Dependensi**
   Gunakan Bun (atau npm) untuk menginstal seluruh modul yang dibutuhkan:
   ```bash
   bun install
   # atau jika menggunakan npm
   # npm install
   ```

3. **Konfigurasi Environment Variables**
   Salin file templat environment ke file `.env` baru:
   ```bash
   cp .env.example .env
   ```
   Buka file `.env` menggunakan teks editor pilihan Anda (seperti VS Code), lalu sesuaikan variabel konfigurasi berikut dengan kredensial Anda (misalnya kunci API Supabase):
   ```env
   VITE_SUPABASE_URL=your_supabase_project_url
   VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
   ```

4. **Menjalankan Server Pengembangan (Development Server)**
   Mulai aplikasi dalam mode *development*:
   ```bash
   bun dev
   # atau
   # npm run dev
   ```
   Aplikasi kini dapat diakses melalui browser pada alamat `http://localhost:5173`.

5. **Membangun untuk Produksi (Production Build)**
   Untuk menguji proses *build* aplikasi sebelum melakukan deployment:
   ```bash
   bun run build
   # atau
   # npm run build
   ```

## 🚢 Panduan Deployment Otomatis

Proyek ini dirancang agar dapat dideploy dengan mudah ke platform **Vercel** dan diintegrasikan dengan **Supabase**:

1. **Deployment ke Vercel:**
   - Masuk ke dashboard [Vercel](https://vercel.com/).
   - Klik **Add New...** -> **Project**, lalu impor repository `saecar/portfolioo`.
   - Pada bagian **Environment Variables**, masukkan variabel yang sama seperti pada file `.env` lokal Anda (`VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, dll).
   - Klik **Deploy**. Vercel secara otomatis akan mendeteksi pengaturan build dan mempublikasikan situs web Anda.

2. **Integrasi Supabase / Railway:**
   - Buat proyek baru di [Supabase](https://supabase.com/).
   - Jalankan skema SQL migrasi untuk tabel yang dibutuhkan (seperti tabel `messages` atau `projects`).
   - Ambil URL proyek dan anon/public key, lalu pasang pada pengaturan Environment Variables di Vercel.

```text
portfolioo/
├── public/                # Aset statis (favicon, gambar, font)

├── tailwind.config.js     # Konfigurasi kustom Tailwind CSS

```
