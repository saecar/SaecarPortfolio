## 🌟 Fitur Utama

- ⚡ **Lightning Fast Performance**: Dibangun menggunakan Vite dan React untuk waktu muat halaman yang instan dan pengalaman pengguna yang mulus.
- 🎨 **Modern UI/UX**: Desain estetis menggunakan Tailwind CSS, lengkap dengan mode Gelap/Terang (*Dark/Light Mode*) otomatis.
- 📱 **Fully Responsive**: Dioptimalkan secara sempurna untuk berbagai ukuran layar, mulai dari perangkat mobile, tablet, hingga desktop beresolusi tinggi.
- 📬 **Interactive Contact Form**: Formulir kontak terintegrasi dengan backend/API eksternal untuk pengiriman pesan langsung yang aman.
- 📊 **Dynamic Project Showcase**: Manajemen dan penyaringan proyek berdasarkan kategori teknologi dengan animasi transisi yang elegan.

## 🛠 Tech Stack & Komponen

Arsitektur aplikasi ini dirancang dengan pendekatan *Component-Based* modern untuk memastikan skalabilitas dan kemudahan pemeliharaan kode (*maintainability*).

- **Frontend**: 
  - [React.js](https://react.dev/) (Library UI berbasis komponen)
  - [Tailwind CSS](https://tailwindcss.com/) (Utility-first CSS framework untuk styling)
  - [Lucide React](https://lucide.dev/) (Kumpulan ikon modern dan bersih)
  - [React Router DOM](https://reactrouter.com/) (Navigasi halaman SPA)
- **Backend / Services (Opsional/Ekstensi)**:
  - [Supabase](https://supabase.com/) / [Railway](https://railway.app/) (Untuk penyimpanan data pesan kontak & analitik sederhana)
- **Build Tool & Bundler**:
  - [Vite](https://vitejs.dev/) (Frontend tooling super cepat)
  - [Bun](https://bun.sh/) / Node.js (JavaScript Runtime & Package Manager)

## 🚀 Cara Pemasangan & Persiapan

Ikuti langkah-langkah di bawah ini untuk menjalankan proyek `portfolioo` secara lokal di komputer Anda.

### Prasyarat
Pastikan Anda telah menginstal perangkat lunak berikut di sistem Anda:
- [Git](https://git-scm.com/)
- [Bun](https://bun.sh/) (Disarankan) atau [Node.js](https://nodejs.org/) (v18+) & npm

### Langkah Instalasi

1. **Clone repositori ke perangkat lokal Anda:**
   ```bash
   git clone https://github.com/saecar/portfolioo.git
   ```

2. **Masuk ke direktori proyek:**
   ```bash
   cd portfolioo
   ```

3. **Install dependencies menggunakan Bun (atau npm):**
   ```bash
   bun install
   # atau jika menggunakan npm
   npm install
   ```

4. **Konfigurasi Environment Variables:**
   Salin file contoh environment dan sesuaikan nilainya dengan konfigurasi Anda.
   ```bash
   cp .env.example .env
   ```
   Buka file `.env` menggunakan teks editor pilihan Anda dan isi variabel yang diperlukan (misalnya URL API, kunci publik Supabase, dll.).

5. **Jalankan server pengembangan (Development Server):**
   ```bash
   bun dev
   # atau
   npm run dev
   ```

6. **Buka browser Anda:**
   Akses `http://localhost:5173` untuk melihat hasil pratinjau aplikasi secara langsung.

### Build untuk Produksi

Untuk menghasilkan file siap produksi (distribusi), jalankan perintah berikut:
```bash
bun run build
# atau
npm run build
```

## 📦 Panduan Deployment Otomatis

### Deploy ke Vercel (Direkomendasikan)
1. Dorong (*push*) perubahan kode Anda ke repositori GitHub: `https://github.com/saecar/portfolioo`.
2. Masuk ke dashboard [Vercel](https://vercel.com/).
3. Klik **Add New...** -> **Project** dan impor repositori `portfolioo`.
4. Vercel akan mendeteksi pengaturan secara otomatis (Framework Preset: *Vite*).
5. Tambahkan Environment Variables Anda di bagian pengaturan Vercel jika diperlukan.
6. Klik **Deploy** dan tunggu proses selesai.

### Integrasi Supabase / Railway
Jika Anda menggunakan Supabase untuk menyimpan pesan dari form kontak:
1. Buat proyek baru di [Supabase](https://supabase.com/).
2. Buat tabel `messages` dengan kolom yang sesuai (misal: `id`, `name`, `email`, `message`, `created_at`).
3. Ambil `VITE_SUPABASE_URL` dan `VITE_SUPABASE_ANON_KEY`, lalu masukkan ke dalam file `.env` lokal maupun Environment Variables di dashboard Vercel/Railway Anda.

## 📂 Struktur Folder

Berikut adalah struktur direktori utama dari proyek `portfolioo`:

```text
portfolioo/
├── public/                 # Aset statis (favicon, gambar publik, dll.)
├── src/
│   ├── assets/             # Aset lokal (gambar, font, stylesheet global)
│   ├── components/         # Komponen UI modular (Navbar, Footer, ProjectCard, dll.)
│   ├── data/               # File data statis (daftar proyek, pengalaman kerja, skill)
│   ├── pages/              # Halaman utama aplikasi (Home, About, Projects, Contact)
│   ├── App.jsx             # Komponen root aplikasi
│   ├── main.jsx            # Titik masuk utama (Entry point) React
│   └── index.css           # Konfigurasi Tailwind & CSS global
├── .env.example            # Contoh variabel lingkungan
├── .gitignore              # Daftar file yang diabaikan oleh Git
├── index.html              # Template HTML utama
├── package.json            # Daftar dependencies dan skrip npm/bun
├── tailwind.config.js      # Konfigurasi kustom Tailwind CSS
└── vite.config.js          # Konfigurasi bundler Vite
```
