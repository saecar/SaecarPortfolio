## 🌟 Fitur Utama

- 🎨 **Modern & Responsive UI**: Antarmuka pengguna yang elegan dan adaptif di semua ukuran layar berkat integrasi Tailwind CSS.
- ⚡ **Lightning Fast Performance**: Dibangun di atas fondasi React.js modern dengan optimasi *bundle size* dan *lazy loading*.
- 📊 **Dynamic Project Showcase**: Manajemen dan pameran proyek interaktif lengkap dengan filter kategori, tautan demo langsung, dan repositori.
- 📬 **Integrated Contact System**: Formulir kontak fungsional yang terhubung langsung dengan sistem backend untuk pengiriman pesan instan.

## 🛠 Tech Stack & Komponen

Arsitektur sistem **portfolioo** dirancang menggunakan standar industri modern untuk memastikan skalabilitas, keamanan, dan performa tinggi:

- **Frontend**: 
  - [React.js](https://reactjs.org/) (UI Library berbasis komponen)
  - [Tailwind CSS](https://tailwindcss.com/) (Utility-first CSS framework untuk styling cepat dan responsif)
  - [Lucide Icons](https://lucide.dev/) / React Icons (Set ikon modern yang ringan)
- **Backend**: 
  - Node.js / Express.js (atau serverless functions untuk handling API endpoints)
- **Database**: 
  - [Supabase](https://supabase.com/) (PostgreSQL-based backend-as-a-service untuk penyimpanan data proyek dan pesan kontak)
- **Authentication**: 
  - Supabase Auth (Untuk manajemen akses admin dashboard)

## 🚀 Cara Pemasangan & Persiapan

Ikuti langkah-langkah di bawah ini untuk menjalankan proyek **portfolioo** di lingkungan lokal Anda (Local Development).

### Prasyarat
Pastikan komputer Anda telah terinstal perangkat lunak berikut:
- [Git](https://git-scm.com/)
- [Node.js](https://nodejs.org/) (Versi 18.x atau terbaru)
- [Bun](https://bun.sh/) (Direkomendasikan) atau NPM

### 1. Clone Repositori
Buka terminal Anda dan jalankan perintah berikut untuk mengkloning repositori:

```bash
git clone https://github.com/saecar/portfolioo.git
cd portfolioo
```

### 2. Instalasi Dependensi
Gunakan `bun` (atau `npm`) untuk menginstal seluruh dependensi yang diperlukan:

```bash
bun install
# atau jika menggunakan npm
npm install
```

### 3. Konfigurasi Environment Variables
Salin file templat environment dan sesuaikan dengan kredensial lokal atau layanan cloud Anda (seperti Supabase):

```bash
cp .env.example .env
```

Buka file `.env` menggunakan teks editor pilihan Anda, lalu isi variabel yang diperlukan:

```env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
PORT=3000
```

### 4. Menjalankan Mode Pengembangan (Development)
Jalankan server lokal untuk mulai mengembangkan atau melihat pratinjau aplikasi:

```bash
bun dev
# atau
npm run dev
```
Aplikasi kini dapat diakses melalui browser pada alamat `http://localhost:5173` (atau port yang ditentukan).

### 5. Membangun untuk Produksi (Build)
Untuk menghasilkan file *bundle* yang di-optimasi untuk produksi:

```bash
bun run build
# atau
npm run build
```

### 🌐 Panduan Deploy Otomatis (Vercel & Supabase)

Anda dapat dengan mudah mendeploy aplikasi ini secara gratis menggunakan **Vercel** dan menghubungkannya dengan **Supabase**.

1. **Deploy ke Vercel**:
   - Dorong (push) kode Anda ke repositori GitHub `saecar/portfolioo`.
   - Masuk ke dashboard [Vercel](https://vercel.com/).
   - Klik **Add New...** -> **Project**, lalu impor repositori `portfolioo`.
   - Pada bagian **Environment Variables**, masukkan variabel dari file `.env` Anda (`VITE_SUPABASE_URL`, dll).
   - Klik **Deploy**. Vercel akan secara otomatis mendeteksi konfigurasi proyek React Anda.

2. **Integrasi Supabase & Railway (Opsional)**:
   - Buat proyek baru di [Supabase](https://supabase.com/).
   - Jalankan skema database SQL yang dibutuhkan untuk tabel proyek dan pesan.
   - Sambungkan URL dan API Key ke Vercel Environment Variables.

## 📂 Struktur Folder

Berikut adalah struktur direktori utama dari proyek **portfolioo**:

```text
portfolioo/
├── public/                 # Aset statis (gambar, favicon, robots.txt)
├── src/
│   ├── assets/             # Gambar, font, dan file styling global
│   ├── components/         # Komponen reusable (Navbar, Footer, ProjectCard, dll)
│   ├── data/               # Data statis portofolio (pengalaman, skill, proyek)
│   ├── hooks/              # Custom React hooks
│   ├── pages/              # Halaman utama (Home, About, Projects, Contact)
│   ├── services/           # Konfigurasi API & Integrasi Supabase
│   ├── utils/              # Fungsi pembantu (helper/formatter)
│   ├── App.jsx             # Komponen root aplikasi
│   └── main.jsx            # Titik masuk (entry point) React DOM
├── .env.example            # Templat variabel lingkungan
├── .gitignore              # Daftar file diabaikan oleh Git
├── package.json            # Daftar dependensi dan skrip npm/bun
├── tailwind.config.js      # Konfigurasi kustom Tailwind CSS
└── README.md               # Dokumentasi proyek
```
