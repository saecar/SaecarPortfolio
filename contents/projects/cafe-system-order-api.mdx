## 🌟 Fitur Utama

- 🔐 **Autentikasi & Otorisasi Berbasis Token**: Sistem keamanan tangguh menggunakan Laravel Sanctum untuk manajemen akses Multi-Role (Admin, Kasir, Customer).
- ☕ **Manajemen Menu Dinamis**: Pengelolaan kategori, kustomisasi varian produk, dan pembaruan status ketersediaan stok secara *real-time*.
- 💳 **Integrasi Payment Gateway Otomatis**: Pemrosesan transaksi pembayaran digital yang seamless dan aman menggunakan Midtrans (QRIS, Virtual Account, E-Wallet).
- 📊 **Manajemen Pesanan & Pelacakan Status**: Alur kerja pemesanan terstruktur mulai dari *Pending*, *Processing*, *Ready*, hingga *Completed*.
- 📈 **Laporan Penjualan & Analitik**: Ekstraksi data transaksi komprehensif untuk kebutuhan evaluasi bisnis kafe.

## 🛠 Tech Stack & Komponen

Proyek ini dibangun menggunakan arsitektur web modern yang skalabel dan mudah dipelihara:

- **Arsitektur Web**: RESTful API Backend
- **Backend Framework**: Laravel (PHP)
- **Database**: PostgreSQL / MySQL
- **Autentikasi**: Laravel Sanctum (Token-based Auth)
- **Payment Gateway**: Midtrans Core API / Snap

## 🚀 Cara Pemasangan & Persiapan

Ikuti langkah-langkah di bawah ini untuk menjalankan proyek secara lokal di komputer Anda.

### Prasyarat
Pastikan sistem Anda telah menginstal perangkat lunak berikut:
- PHP >= 8.2
- Composer
- Node.js & NPM / Bun
- Git
- Database Server (MySQL / PostgreSQL)

### 1. Kloning Repositori
```bash
git clone https://github.com/saecar/cafe-system-order-api.git
cd cafe-system-order-api
```

### 2. Instalasi Dependensi Backend (PHP)
```bash
composer install
```

### 3. Konfigurasi Environment Variables (`.env`)
Salin file `.env.example` menjadi `.env`, lalu sesuaikan konfigurasi database dan kredensial layanan pihak ketiga Anda.
```bash
cp .env.example .env
```

Generate kunci aplikasi Laravel:
```bash
php artisan key:generate
```

Buka file `.env` dan sesuaikan bagian berikut:
```env
APP_NAME="Cafe System Order API"
APP_ENV=local
APP_KEY=
APP_DEBUG=true
APP_URL=http://localhost:8000

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=cafe_system_db
DB_USERNAME=root
DB_PASSWORD=

MIDTRANS_SERVER_KEY=your-midtrans-server-key
MIDTRANS_CLIENT_KEY=your-midtrans-client-key
MIDTRANS_IS_PRODUCTION=false
```

### 4. Migrasi & Seeding Database
Jalankan perintah migrasi untuk membuat tabel database beserta data dummy awal:
```bash
php artisan migrate --seed
```

### 5. Menjalankan Server Lokal
Jalankan server pengembangan Laravel:
```bash
php artisan serve
```
API kini dapat diakses melalui `http://localhost:8000`.

## 🌐 Panduan Deployment Otomatis

Proyek ini dirancang agar dapat dideploy dengan mudah ke platform cloud modern seperti Railway dan Supabase.

### Integrasi Database (Supabase)
1. Buat proyek baru di [Supabase](https://supabase.com).
2. Dapatkan kredensial koneksi Database PostgreSQL (Host, Port, User, Password, Database Name).
3. Masukkan kredensial tersebut ke dalam pengaturan Environment Variables pada platform hosting Anda.

### Deployment ke Railway / Vercel
1. Hubungkan repositori GitHub `saecar/cafe-system-order-api` ke [Railway](https://railway.app).
2. Tambahkan layanan Database PostgreSQL atau gunakan integrasi Supabase.
3. Konfigurasikan Environment Variables berikut di dasbor Railway:
   - `APP_ENV=production`
   - `APP_DEBUG=false`
   - `APP_KEY=` (Generate kunci baru untuk produksi)
   - `DB_CONNECTION=pgsql` (atau mysql)
   - Seluruh kredensial database dan Midtrans Production.
4. Railway akan otomatis mendeteksi proyek PHP/Laravel dan menjalankan perintah build serta start.
