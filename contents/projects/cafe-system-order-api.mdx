## 🌟 Fitur Utama

- 🧾 **Manajemen Pesanan Real-time**: Pencatatan dan pemantauan status pesanan dari pelanggan secara *live* mulai dari *pending*, *processing*, hingga *completed*.
- 💳 **Integrasi Payment Gateway (Midtrans)**: Otomatisasi transaksi pembayaran digital menggunakan QRIS, *Virtual Account*, dan *e-wallet* dengan webhook handler yang aman.
- 📦 **Manajemen Menu & Inventaris**: Pengelolaan kategori produk, ketersediaan stok, harga, dan variasi menu kafe secara dinamis.
- 📊 **Laporan & Analitik Penjualan**: Rekapitulasi data transaksi harian, bulanan, dan produk terlaris untuk kebutuhan bisnis.
- 🔒 **Autentikasi & Otorisasi Berbasis Peran (RBAC)**: Keamanan tingkat lanjut menggunakan Laravel Sanctum untuk membedakan hak akses antara Admin, Kasir, dan Pelanggan.

## 🛠 Tech Stack & Komponen

Proyek ini dibangun menggunakan arsitektur web modern yang memisahkan antara layanan Backend API dan pengelolaan basis data relasional yang optimal.

### Arsitektur Web
- **Backend**: Laravel (PHP Framework) sebagai core RESTful API yang menangani business logic, routing, dan middleware.
- **Database**: MySQL / PostgreSQL untuk penyimpanan data transaksional yang konsisten dan relasional.
- **Authentication**: Laravel Sanctum (Token-based API Authentication).
- **Payment Gateway**: Midtrans Core API / Snap Integration.

## 🚀 Cara pemasangan & Persiapan

Ikuti langkah-langkah di bawah ini untuk menyiapkan lingkungan pengembangan lokal Anda:

### 1. Prasyarat Sistem
Pastikan komputer Anda telah menginstal perangkat lunak berikut:
- PHP >= 8.2
- Composer
- Node.js & NPM / Bun
- Git
- MySQL / PostgreSQL

### 2. Kloning Repositori
Buka terminal Anda dan jalankan perintah berikut:
```bash
git clone https://github.com/saecar/cafe-system-order-api.git
cd cafe-system-order-api
```

### 3. Instalasi Dependensi Backend (PHP/Composer)
```bash
composer install
```

### 4. Konfigurasi Lingkungan (`.env`)
Salin file `.env.example` menjadi `.env` lalu sesuaikan konfigurasi database dan kunci API Anda:
```bash
cp .env.example .env
```
Generate kunci enkripsi aplikasi Laravel:
```bash
php artisan key:generate
```

### 5. Migrasi dan Seeder Database
Pastikan layanan database Anda sudah aktif, lalu jalankan migrasi tabel beserta data dummy (opsional):
```bash
php artisan migrate --seed
```

### 6. Menjalankan Server Pengembangan Lokal
Jalankan server lokal menggunakan artisan:
```bash
php artisan serve
```
Aplikasi API kini dapat diakses melalui `http://localhost:8000`.
