## 🌟 Fitur Utama

- 🛒 **Manajemen Pesanan Real-Time**: Alur pemesanan end-to-end dari pelanggan, dapur (kitchen display), hingga status siap saji.
- 💳 **Integrasi Payment Gateway**: Otomatisasi transaksi menggunakan Midtrans (QRIS, Virtual Account, E-Wallet, Kartu Kredit).
- 🔐 **Autentikasi Berbasis Token**: Keamanan endpoint API menggunakan Laravel Sanctum untuk otorisasi Multi-Role (Admin, Kasir, Dapur, Pelanggan).
- 📊 **Laporan & Analitik Keuangan**: Rekapitulasi data penjualan harian, mingguan, dan bulanan secara akurat untuk kebutuhan bisnis.

---

## 🛠 Tech Stack & Komponen

Proyek ini dibangun menggunakan arsitektur modern standar Industri Web Development:

- **Arsitektur Web**: RESTful API Backend
- **Backend Core**: PHP 8.2+, Laravel 11 Framework
- **Database & Storage**: MySQL / PostgreSQL dengan Eloquent ORM
- **Authentication**: Laravel Sanctum (Token-based Auth)
- **Payment Gateway**: Midtrans PHP SDK
- **Deployment & Hosting**: Railway / Vercel (Serverless/Containerized)

## 🚀 Cara Pemasangan & Persiapan

Ikuti langkah-langkah di bawah ini untuk menyiapkan lingkungan pengembangan lokal Anda.

### Prasyarat
Pastikan komputer Anda telah menginstal:
- PHP >= 8.2
- Composer
- Node.js & NPM / Bun
- Git
- MySQL / PostgreSQL

### 1. Kloning Repositori
Buka terminal Anda dan jalankan perintah berikut:
```bash
git clone https://github.com/saecar/cafe-system-order-api.git
cd cafe-system-order-api
```

### 2. Instalasi Dependensi PHP & JavaScript
```bash
composer install
npm install
# atau jika menggunakan bun
bun install
```

### 3. Konfigurasi Environment Variables (`.env`)
Salin file `.env.example` menjadi `.env` lalu sesuaikan konfigurasi database dan kunci API Anda:
```bash
cp .env.example .env
```

Generate kunci aplikasi Laravel:
```bash
php artisan key:generate
```

Sesuaikan konfigurasi berikut pada file `.env` Anda:
```env
APP_NAME="Cafe System Order API"
APP_ENV=local
APP_KEY=
APP_DEBUG=true
APP_URL=http://localhost:8000

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=cafe_system_db
DB_USERNAME=root
DB_PASSWORD=

# Konfigurasi Midtrans
MIDTRANS_MERCHANT_ID=your_merchant_id
MIDTRANS_CLIENT_KEY=your_client_key
MIDTRANS_SERVER_KEY=your_server_key
MIDTRANS_IS_PRODUCTION=false
```

### 4. Migrasi & Seeder Database
Jalankan migrasi database beserta data dummy (seeder) untuk pengujian:
```bash
php artisan migrate --seed
```

### 5. Menjalankan Server Pengembangan
Jalankan server lokal Laravel:
```bash
php artisan serve
```
Aplikasi API kini dapat diakses melalui `http://localhost:8000`.

## 🌐 Panduan Deployment

### Deploy Otomatis ke Railway / Vercel
Proyek ini dirancang agar mudah di-deploy ke platform Cloud seperti Railway atau Vercel:

1. **Hubungkan Repositori**: Buat proyek baru di [Railway](https://railway.app/) atau [Vercel](https://vercel.com/) dan hubungkan dengan repositori GitHub `saecar/cafe-system-order-api`.
2. **Atur Environment Variables**: Masukkan seluruh variabel `.env` (terutama konfigurasi database dan Midtrans Server Key) ke dalam menu *Environment Variables* di dashboard Railway/Vercel.
3. **Build & Start Command**:
   - Build Command: `composer install --optimize-autoloader --no-dev`
   - Start Command: `php artisan config:cache && php artisan migrate --force && php artisan serve --host=0.0.0.0 --port=$PORT`
4. **Deploy**: Klik tombol *Deploy* dan tunggu hingga proses build selesai. API Anda kini siap digunakan secara publik.
